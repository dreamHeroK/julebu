## 迭代 2：改成逐词输入框 + 修串题 bug

- **串题 bug 根因**：`createTypingEngine()` 初始化末尾会同步 `emit()`，若 `loadSentence` 里 `engine = createTypingEngine(...)` 尚未赋值，`renderWords` 里 `engine` 仍指向旧引擎 → 词块用上一句、中文已是下一句。修法：销毁时先 `engine = null`，创建后手动 `renderWords()`。
- **改为每词一个 `<input class="wb wb-input">`**：词块即输入框，`readOnly` 控制完成态；`renderWords` 只 toggle class / 同步 value / 把焦点交给当前词（仅当 activeElement 是 body 或另一个 wb-input 时才抢焦点，避免抢掉按钮焦点）。
- **宽度**：`ch` 估算会宽出约 35px 导致过早换行 → 用 canvas `measureText` 实测 + 32px padding，`resize` 时重算。
- 实测：首词聚焦 / 答对跳词 / 答错标红 420ms 清 / 整句完成 / 切题不再串 / 空退格回退上一词 / Tab 提示 / 空提交不推进，全部通过，控制台 0 报错。
